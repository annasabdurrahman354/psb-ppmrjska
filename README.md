# Situs Pendaftaran Pondok Pesantren Mahasiswa Roudlotul Jannah Surakarta (PPM RJSKA)

Selamat datang di repositori kode untuk situs pendaftaran online Pondok Pesantren Mahasiswa Roudlotul Jannah Surakarta.

## Deskripsi

Proyek ini merupakan sistem informasi yang dibangun untuk memfasilitasi proses Penerimaan Santri Baru (PSB) secara online bagi calon mahasiswa yang ingin mendaftar ke Pondok Pesantren Mahasiswa Roudlotul Jannah Surakarta.

## Informasi Website

-   **Website Utama Pondok:** [ppmrjska.com](https://ppmrjska.com)
-   **Website Pendaftaran Santri Baru:** [psb.ppmrjska.com](https://psb.ppmrjska.com)

## Tentang Pondok Pesantren Mahasiswa Roudlotul Jannah Surakarta

Pondok Pesantren Mahasiswa Roudlotul Jannah Surakarta (PPM RJSKA) adalah lembaga pendidikan Islam yang berlokasi di Surakarta, Jawa Tengah. PPM RJSKA bertujuan untuk membina mahasiswa yang memiliki pemahaman agama yang kuat, berakhlak mulia, serta mampu berkontribusi positif bagi masyarakat.

## Teknologi yang Digunakan (Berdasarkan Struktur Proyek Umum Laravel)

-   **Framework:** Laravel
-   **Frontend:** Blade templating, dengan Livewire atau Inertia.js
-   **Backend:** PHP
-   **Database:** MySQL
-   **Administrasi:** Filament PHP
